# 中古相場チェック（ブックオフ・aucfan経由）

## なぜこのスキルが必要か

`resale_research.html`（せどりリサーチ電卓）は、商品ごとに「中古最安値」と「出品者数」を入力すると価格提案と売却目安日数を計算するツール。当初はAmazon.co.jpのデータで運用する想定だったが、検証の結果、この環境では次のことが判明した。

- `mcp__Claude_Browser__*` / `mcp__claude-in-chrome__*`（ブラウザツール）は、amazon.co.jp・rakuten.co.jp・mercari.com・aucfan.com・bookoff.co.jp を含む主要なEC/マーケットプレイス系ドメインを**ポリシーレベルで一律ブロック**している。CAPTCHAやボット検知以前に、ページ自体を開けない。
- 一方、`WebFetch` ツールは同じドメインでも通ることがある。ただし取得できるのはページの静的HTMLのみで、Amazon・楽天・メルカリの中古出品欄は**JavaScriptで動的描画**されているため、WebFetchでは価格や出品者数を抽出できない（実測済み）。
- 例外的に、**ブックオフオンライン**（shopping.bookoff.co.jp）は価格情報が静的HTMLに含まれており、WebFetchで実際に価格を取得できた（実測: 書籍で¥1,650を正しく取得）。**aucfan.com**（ヤフオク!・メルカリの相場集計サイト）もWebFetchで開け、対象商品の相場データがあれば取得できる。

つまりこのスキルは「Amazonの代わりに、実際にデータが取れる情報源を使う」という位置づけ。Amazon自体の数値が必要な場合は `check-amazon-used-price` スキル（この環境では動作しないことが判明済み、別環境向けに温存中）を参照するようユーザーに伝える。

## 対象商品の特定

`check-amazon-used-price` と同じ考え方:

1. ユーザーが商品名・ISBN・JANコードを直接指定した場合はそれを使う。
2. 指定がない場合は `resale_research.html` から拾おうとするが、localStorage（キー `resaleItems_v1`）はブラウザ・端末ごとに独立しているため、このセッションのブラウザには通常データが無い。空だった場合はその旨を正直に伝え、商品名を直接聞くか「書き出す」データの共有を依頼する（架空のデータを作らない）。

## 調べ方（WebFetchのみを使う。Browserツールでこれらのサイトを開こうとしない）

各商品について、以下を順に行う。

### 1. ブックオフオンライン（最優先・最も信頼できる実売価格）

```
WebFetch url: https://shopping.bookoff.co.jp/search/keyword/<商品名またはISBN/JANコード>/
prompt: "このページに掲載されている「<商品名>」の中古販売価格と在庫状況を教えてください。複数の商品が表示されている場合は、対象商品に最も近いものを教えてください。"
```

これは「中古最安値」に相当する実際の販売価格として使える。ブックオフは書籍・CD・DVDいずれも扱っているので、カテゴリを問わず第一候補にする。

### 2. aucfan（相場・落札傾向の補足情報）

```
WebFetch url: https://aucfan.com/search1/q-<商品名>/s-mix/
prompt: "このページに「<商品名>」の落札相場・平均価格・直近の落札件数や日付など、売れ行きの目安になる情報があれば教えてください。"
```

ヤフオク!・メルカリの過去の落札実績を集計したサイトなので、「どのくらいの頻度で売れているか」の参考になる。ただし対象商品によっては該当データが無いことも多い（実測済み）ので、無ければ「該当データなし」と正直に報告する。

### 3. 補足を試してもよいが期待しすぎない情報源

Amazon・楽天市場・メルカリはWebFetchで開けても中古出品の価格情報が動的描画で取得できないことが多い。時間をかけて粘るより、上記1・2で十分な情報が得られなければ、その旨を伝えて終える方が誠実。403エラー（楽天市場で実測）が返ってきたら、それ以上リトライしない。

## 報告フォーマット

```
商品名 → ブックオフ実売価格: ¥X（在庫あり/なし）／aucfan相場: ¥Y（参考・データがあれば）
```

データが片方しか取れなかった場合は、取れた方だけを報告する。両方取れなかった場合:

```
商品名 → ブックオフ・aucfanどちらにも該当データが見つかりませんでした
```

## resale_research.html への当てはめ方

ブックオフの実売価格は、ツールの「中古最安値」欄にほぼそのまま使える参考値になる（ブックオフは全国チェーンの実店舗価格なので、Amazon中古相場と同程度かやや高めのことが多い点は伝えておくとよい）。「出品者数」に相当する数値はブックオフ・aucfanからは直接取れないため、その欄は空欄のままか、aucfanの落札件数などを参考情報としてメモ欄に書き添えるよう案内する。

ツール側のデータに直接書き戻せる場合（`resale_research.html` の同一ブラウザタブが開いている場合）は、書き戻してよいか一言確認してから `price` フィールド等を更新する。
