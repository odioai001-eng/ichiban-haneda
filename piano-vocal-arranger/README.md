# Piano+Vocal Arranger (MVP)

ピアノ＋ボーカルだけの音源に、ベース・ギター・ドラムを自動で追加してバンドアレンジのミックスを作るツールです。

## 仕組み（ルールベースMVP）

外部のAIモデルやサウンドフォントには依存せず、Python標準的な音声処理ライブラリとnumpy合成だけで完結します。

1. **解析** (`backend/audio_analysis.py`): librosaでテンポ・ビート・小節の区切りを検出し、小節ごとにクロマ特徴量からコード（メジャー/マイナートライアド、24種類のテンプレートとのコサイン類似度）を推定します。
2. **自動編曲** (`backend/arranger.py`): ジャンル別のパターンテンプレート（ロック/バラード/ボサノバ）に沿って、検出したコードからベース・ギター・ドラムのノートイベントを生成します。
3. **音源合成** (`backend/synth.py`): numpyだけで各パートを合成します（ベース/ギターは倍音合成＋エンベロープ、ドラムはノイズ＋周波数スイープ）。外部サウンドフォント不要。
4. **ミックス** (`backend/mixer.py`): 原曲（ピアノ＋ボーカル）と生成した各パートをレベル調整して合成し、WAV出力します。

この設計にした理由: ピアノパートの完全な採譜（音符レベル）は精度もセットアップコストも高いため、MVPでは「テンポ・拍・コード」という粗い情報だけで伴奏を組み立てます。原曲の音声はそのまま使うので、ピアノ・ボーカルの音質は劣化しません。

## セットアップ

```bash
pip install -r requirements.txt
```

## 起動

```bash
cd backend
uvicorn main:app --reload --port 8000
```

ブラウザで `http://localhost:8000` を開き、音源をアップロードしてジャンルを選ぶとアレンジされたミックスがその場で試聴・ダウンロードできます。

## CLIでの実行

```bash
cd backend
python cli.py path/to/input.wav --genre rock --out arranged.wav
```
